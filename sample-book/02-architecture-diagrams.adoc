== Chapter 2: Architecture & Mermaid Diagrams

This chapter showcases various interactive Mermaid.js diagrams embedded inside AsciiDoc code blocks with custom width controls.

=== 1. System Sequence Diagram (Width: 600px)

[source,mermaid,width=600]
----
sequenceDiagram
    autonumber
    actor User as Author / Writer
    participant Editor as Monaco Editor
    participant Worker as WebWorker Engine
    participant Preview as Live Preview
    participant Exporter as EPUB/HTML Exporter

    User->>Editor: Type AsciiDoc Markup
    Editor->>Worker: Off-thread Parsing (Asciidoctor)
    Worker-->>Preview: Transformed HTML Fragment
    Preview->>Preview: Render Mermaid SVG & Styling
    User->>Exporter: Trigger Export to HTML / EPUB3
    Exporter-->>User: Download Finished Publication File
----
