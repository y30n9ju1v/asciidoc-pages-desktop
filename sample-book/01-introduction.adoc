== Chapter 1: Introduction & Basic Syntax

AsciiDoc is a human-readable text document format for writing technical notes, documentation, articles, books, and presentation slides.footnote:[AsciiDoc was created by Stuart Rackham in 2002 and is now maintained as an OASIS technical committee standard.]

The rendering engine used in this project, Asciidoctor.js, is a WebAssembly build of the Ruby-based Asciidoctor processor.footnote:[See https://asciidoctor.org for the full specification and reference implementation.]
