=== Math Formulas (STEM)

AsciiDoc Studio renders inline and block math via KaTeX. For example, the time complexity of binary search is stem:[O(\log n)], and more generally the master theorem gives us stem:[T(n) = aT(n/b) + f(n)] for divide-and-conquer recurrences.

The closed-form solution for the number of pairwise comparisons in a full binary tournament is shown in <<eq-sum-identity>>:

[#eq-sum-identity]
.Pairwise comparison total
[stem]
++++
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
++++

As <<eq-sum-identity>> shows, this identity also underlies the closed-form
running time of any single-pass pairwise comparison algorithm. The PDF keeps
the formula centered while placing its publication number at the right edge.
